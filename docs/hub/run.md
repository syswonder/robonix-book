# 运行

本页说明在本地 Robonix Hub 中构建软件包、启动 Robonix 并查看日志。前提是当前工作区已有部署清单，见[配置机器人](./configure.md)。

## 构建软件包

部署引用的软件包需要先下载和构建。在 `更新` 页点 `更新全部软件包`，本地 Robonix Hub 拉取代码并逐个构建。任务日志显示进度；构建失败时，日志给出出错的软件包和原因。

## 启动与停止

在 `概览` 页点 `启动`，状态依次变为 `启动中` 和 `运行中`，按钮变为 `停止`。同一台机器人同一时间只能运行一个工作区的 Robonix。`概览` 页还可以开启开机自启。

## 查看日志

`日志` 页左侧列出最近几次运行，每次启动对应一条。日志上方每个组件一个标签，`rbnx 输出` 是启动过程本身的输出。可以按关键字筛选、跟随最新日志，或下载完整日志。

![日志页。左侧是运行列表，上方是组件标签和筛选框。](/img/hub/04-logs.webp)

## 连接 robonix-client

`概览` 页给出机器人地址和 Atlas 端口，在 robonix-client 中填入即可连接，Liaison 地址留空。某个组件只监听本机时，`概览` 页提供 `允许其他机器连接`，确认后保存为新版本，下次启动生效。

:::warning[只在可信网络中开放]
`允许其他机器连接` 让同一网络中的任何机器都能连接该组件。
:::
