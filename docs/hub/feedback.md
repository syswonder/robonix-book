# 反馈问题

遇到问题或有建议时，直接在页面上提交反馈。反馈会连同排查所需的信息一起发给维护者。本地 Robonix Hub 和 Robonix Hub Cloud 都可以提交。

## 提交反馈

1. 点页面右上角的反馈按钮 ①。

   ![反馈按钮位于账户名称旁边，标记为 1。](/img/hub/07-feedback-button.webp)

2. 在 `反馈对象` ① 中选择 `Robonix`、`Robonix Hub` 或 `Robonix Hub Cloud`。
3. 在描述框 ② 中写明看到的现象、期望的结果，以及出问题前做的操作。
4. 检查随附信息。在本地 Robonix Hub 提交时，反馈附带系统与硬件、版本、最近的日志和 `Robonix Hub 设置`；点 `查看` ③ 阅读原文，取消勾选的项不会发送。`当前部署清单` ④ 默认不勾选，勾选后其中的密钥会替换为占位符。
5. 点 `发送` ⑤。

![反馈对话框。依次是反馈对象、问题描述、随附内容列表和发送按钮。](/img/hub/07-feedback-dialog.webp)

点 `查看` 展开的就是将要发送的原文：

![展开“版本”一项，显示将要发送的版本信息原文。](/img/hub/07-feedback-preview.webp)

发送成功后，对话框显示 `已发送。感谢您的反馈。`

![反馈已发送的提示。](/img/hub/07-feedback-sent.webp)

在 Robonix Hub Cloud 提交时，反馈附带浏览器信息。

## 提交之后

- 维护者收到邮件通知，在管理后台查看和处理。
- 反馈和附件保存 180 天，仅管理员可见。
- 每个账户每天最多提交 20 条。

## 无法连接云端时

本地 Robonix Hub 无法连接 Robonix Hub Cloud 时，反馈对话框提供 `下载反馈包`。下载的文件包含同样的内容，可以另行发给维护者。

## 写好一条反馈

- 一条反馈只说一个问题。
- 写清复现步骤，具体到点了哪个按钮、填了什么。
- 页面上有报错时，原样抄下报错文字。
- 运行相关的问题，保留 `最近的日志` 的勾选。
