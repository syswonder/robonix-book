# 账户

Robonix Hub Cloud 和本地 Robonix Hub 使用同一个账户。本页说明注册、激活和登录。完成后，可以在 [hub.robonix.ai](https://hub.robonix.ai) 和机器人上的本地 Robonix Hub 中登录。

## 注册并激活账户

1. 在 [hub.robonix.ai](https://hub.robonix.ai) 注册，填写邮箱和显示名称。
2. 打开邮件中的链接，输入邮件中的验证码。
3. 阅读个人信息出境告知，逐项确认：年满十八周岁、同意将个人信息提供至位于中华人民共和国境外的服务器、同意许可协议。
4. 设置密码。

设置密码后，账户即激活，页面进入 Robonix Hub Cloud。在账户设置中绑定身份验证器后，登录时还需要输入一次性验证码。

## 登录与退出

本地 Robonix Hub 的登录页使用同一组邮箱和密码。登录状态保留 7 天，本地 Robonix Hub 重启后不需要重新登录。点页面右上角账户菜单中的 `退出登录` 结束登录。

## 许可协议更新与注销

许可协议更新后，需要先在 Robonix Hub Cloud 上重新同意，之后才能继续使用 Robonix Hub Cloud 和登录本地 Robonix Hub。

账户可以在 `个人主页` 注销，注销 7 天后删除全部数据。
