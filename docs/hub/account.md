# 账户

Robonix Hub 和 Robonix Console 使用同一个账户。本页说明激活和登录。完成后，可以在 [hub.robonix.ai](https://hub.robonix.ai) 和机器人上的 Robonix Console 中登录。

## 激活账户

Robonix Hub 不开放自行注册，账户由管理员用邮箱创建。创建后，该邮箱收到邀请邮件，内含激活链接和验证码，72 小时内有效，只能使用一次。

1. 打开邮件中的链接，输入邮件中的验证码。
2. 阅读个人信息出境告知，逐项确认：年满十八周岁、同意将个人信息提供至位于中华人民共和国境外的服务器、同意许可协议。
3. 设置密码。

设置密码后，账户即激活，邮箱同时完成验证，页面进入 Robonix Hub。在账户设置中绑定身份验证器后，登录时还需要输入一次性验证码。

## 登录与退出

Robonix Console 的登录页使用同一组邮箱和密码。登录状态保留 7 天，Robonix Console 重启后不需要重新登录。点左侧栏底部的账户名，在菜单中点 `退出登录` 结束登录；手机上账户菜单在页面右上角。

## 许可协议更新与注销

许可协议更新后，需要先在 Robonix Hub 上重新同意，之后才能继续使用 Robonix Hub 和登录 Robonix Console。

账户可以在 `个人主页` 注销，注销 7 天后删除全部数据。
