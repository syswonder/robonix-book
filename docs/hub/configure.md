# 配置机器人

一台机器人的全部配置写在一份部署清单中：系统服务的参数，以及使用的原语、服务和技能。部署清单和它的版本历史保存在部署目录中。本页说明如何在本地 Robonix Hub 中得到并修改部署清单，前提是已[安装](./install.md)并登录本地 Robonix Hub。

## 部署目录

部署目录是机器人上运行 `rbnx boot` 的目录，一套部署的全部文件都在其中：

| 内容 | 说明 |
|---|---|
| `robonix_manifest.yaml` | 部署清单 |
| `primitives/`、`services/` | 本机软件包，即部署清单中以本地路径引用的软件包 |
| `scripts/`、`config/`、`sim/` 等 | 整机配置附带的脚本、配置文件和仿真场景 |
| `.portal/history.git` | 本地 Robonix Hub 为这套部署保存的版本历史 |

本地 Robonix Hub 安装时创建默认部署目录 `~/.local/share/robonix-hub/deployments/default`，名称为 `Default deployment`，其版本历史保存在 `~/.local/share/robonix-hub/state/history.git`。本地 Robonix Hub 在列表中记录每个部署目录的名称和路径。

一台机器人可以有多个部署目录，每个目录是一套独立的部署，相互之间不会覆盖。同一时间只有一个当前部署目录：`概览` 页的启动与停止、`部署` 页的修改、`版本` 页的回滚，都作用于当前部署目录。各套部署使用相同的端口，所以同一时间也只有当前部署目录能运行 Robonix。`概览` 页标题 `本机` 旁边的下拉框用于切换当前部署目录。

以下情况会增加部署目录：

- 从目录安装整机配置或从云端下载部署时，若当前部署目录为空，则放入当前部署目录；若已有部署，则在 `~/.local/share/robonix-hub/deployments/` 下新建一个部署目录放入，并切换过去，原部署目录保持不变。
- 在 `设置` 页的 `部署目录` 一节新建。填写名称和路径：路径指向已有的部署目录时，例如此前在命令行中手动搭建的部署，本地 Robonix Hub 直接接管该目录；路径不存在时新建空目录。

示例：

1. 新安装的本地 Robonix Hub 只有一个空的部署目录 `Default deployment`。从目录安装 TIAGo 的整机配置，配置放入 `Default deployment`。
2. 再从目录安装 Piper 双臂的整机配置。`Default deployment` 中已有 TIAGo 的部署，于是本地 Robonix Hub 新建部署目录 `dual_piper`，放入 Piper 的部署并切换过去。TIAGo 的部署仍在 `Default deployment` 中。
3. 需要运行 TIAGo 时，在 `概览` 页的下拉框中切换回 `Default deployment`，再启动。

部署目录可以在 `设置` 页重命名和删除。删除时，由本地 Robonix Hub 创建的目录连同文件一起删除，用户指定的已有目录只从列表中移除，文件保留。最后一个部署目录不能删除。

## 从目录安装整机配置

1. 打开 `目录`，选择 `机器人` 分类，搜索机型。
2. 打开该条目，点 `安装到本机`。

整机配置连同其本机软件包和脚本一起下载，并保存为第一个版本。当前部署目录已有部署时，本地 Robonix Hub 新建一个部署目录并切换过去，见上一节。

## 部署页

`部署` 页顶端一栏始终可见：左侧是分区导航，右侧是 `编辑 YAML` 和 `保存为新版本`。

![部署页。顶端是分区导航和保存按钮，下方依次列出系统服务、自带服务和软件包，可停用的项右侧有开关。](/img/hub/03-deploy-page.webp)

| 分区 | 内容 |
|---|---|
| 系统服务 | atlas、executor、soma 为必需；pilot、liaison、vitals、scene 可用开关停用，停用后写为 `status: disabled` |
| 自带服务 | Robonix 源码中的服务，例如语音和记忆，路径以 `${ROBONIX_SOURCE_PATH}` 开头；开关打开即加入部署 |
| 原语、服务、技能 | 部署使用的软件包，可以从目录或本机目录添加 |
| 环境变量 | 只对这一份部署生效的环境变量 |

## 修改参数

点开一项即可修改其配置。提供严格格式配置说明（`config.spec`）的软件包显示为表单：每个参数一行，右侧显示当前值或默认值；分组和嵌套对象默认收起，右侧显示参数总数和已设置的个数；点开一行才显示输入框和说明。

![配置表单。分组收起时只占一行；展开的参数显示说明和输入框，长说明可点“更多”展开。](/img/hub/03-edit-config.webp)

参数的值是部署中另一个条目的名称时，例如激光雷达由哪个原语提供，该参数显示为选择框。下拉列表中，提供所需能力约定（Contract）的条目排在最前面。

![选择提供方。lidar2d 参数的选择框中已选中 tiago_lidar。](/img/hub/03-provider.webp)

没有严格格式说明的软件包，配置按键值对列出，可以直接修改、删除和添加。

## 设置本机环境变量

部署在必填参数中引用了尚未设置的变量时，`部署` 页和 `概览` 页顶端显示提示。点 `设置` 填写，值保存为本机环境变量，本机所有部署共用，不会上传。

![未设置的变量提示。列出 VLM_API_KEY、VLM_BASE_URL 和 VLM_MODEL，右侧是“设置”按钮。](/img/hub/03-variables.webp)

`设置` 页的 `本机环境变量` 可以查看、添加和修改全部本机变量。部署自己的环境变量与本机变量同名时，以部署为准。

## 保存版本与回滚

点 `保存为新版本`，填写修改说明，对话框列出修改前后的对比。`版本` 页列出全部版本，可以与当前清单对比，也可以回滚。Robonix 正在运行时，回滚在下次启动时生效。
