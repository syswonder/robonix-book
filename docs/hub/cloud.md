# 目录与云端

本页说明 Robonix Hub Cloud 提供的功能：软件包目录、收藏、云端副本和 API。目录无需登录即可浏览，收藏和云端副本需要登录。

## 软件包目录

`目录` 按 `技能`、`服务`、`原语`、`机器人` 分类，可以搜索，并按热度、更新时间或名称排序。软件包页列出版本、说明、提供的能力约定和 README；能力约定可以逐层查看接口字段。点 `收藏` 收藏软件包或机器人，收藏列在 `个人主页`。

机器人整机配置的页面列出 `使用的软件包`：按原语、服务、技能分组列出部署清单中的软件包。目录中有对应条目的，点击打开其软件包页；其余的链接到各自的仓库，或标注为 `本机软件包`，即随整机配置存放在同一仓库中的软件包。

## 云端副本

本地 Robonix Hub `概览` 页的 `云端` 一栏用于：

- `上传到云端`：把这台机器人的部署和版本上传到当前账户。上传前列出将要发送的内容，确认后才上传。
- `从云端下载`：把账户中的副本下载到新的部署目录。

`我的机器人` 列出登录过本账户的机器人及其在线状态，可以让某台机器人退出登录。上传的副本也列在这里，只能查看和下载；修改需要在机器人的本地 Robonix Hub 中进行。

## 用量

`用量` 页显示账户在 Robonix Hub Cloud 中占用的存储空间：已用空间与上限、各类别的大小和条数、各台机器人的版本数和大小，以及机器人数量等上限。手机上从右上角的账户菜单进入。目前计入的只有云端副本。上传会超出上限时，上传被拒绝，云端已有的数据保持不变。

## API

Robonix Hub Cloud 提供只读 REST API，前缀为 `https://hub.robonix.ai/api/v1`。目录、软件包和能力约定无需令牌；账户、收藏和机器人需要个人访问令牌，在 `个人主页` 的 `API` 一节生成。接口说明见 `https://hub.robonix.ai/api/v1/openapi.json`。

## 服务状态

[hub.robonix.ai/status](https://hub.robonix.ai/status) 显示网站、数据库、账户与登录、邮件、目录同步和备份等是否正常，并链接到外部监控的历史可用率。
