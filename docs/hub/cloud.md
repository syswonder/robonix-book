# 目录与云端

本页说明 Robonix Hub 提供的功能：软件包目录、收藏、云端备份、分享和 API。目录无需登录即可浏览，收藏和云端备份需要登录。

## 软件包目录

`目录` 按 `技能`、`服务`、`原语`、`机器人` 分类，可以搜索，并按热度、更新时间或名称排序。软件包页列出版本、说明、提供的能力约定和 README；能力约定可以逐层查看接口字段。详情里的标签可以点击，打开只显示带这个标签的软件包的目录。点 `收藏` 收藏软件包或机器人，收藏列在 `个人主页`。

机器人整机配置的页面列出 `使用的软件包`：按原语、服务、技能分组列出部署清单中的软件包。目录中有对应条目的，点击打开其软件包页；Robonix 源码中的服务标注为 `Robonix 内置`，链接到 Robonix 仓库；其余的链接到各自的仓库，或只显示本地路径，即随整机配置存放在同一仓库中的软件包。

## 云端备份

云端备份是一个部署目录在当前账户中的备份，包括部署清单和全部版本。每个部署目录各有一份备份，同一台机器人上的几个部署目录互不覆盖。Robonix Console `概览` 页的 `云端备份` 一栏作用于当前部署目录：

- `上传此部署`：把当前部署目录的部署清单和全部版本上传到当前账户，替换它的上一份备份。上传前列出将要发送的内容，确认后才上传。
- `从云端下载`：选择一份备份（以“机器人 · 部署”标识），把它的全部版本下载到新的部署目录，也可以改为覆盖当前部署目录，见[配置机器人](./configure.md#部署目录)。
- `导入分享链接`：粘贴别人的分享链接，打开后安装到这台机器人。

`我的机器人` 列出登录过本账户的机器人及其在线状态，可以把某台机器人从本账户移除。上传的备份也列在这里，注明来自哪个部署，只能查看和下载；修改需要在该机器人的 Robonix Console 中进行。

## 分享部署

`我的机器人` 页中，已上传的云端备份旁有 `分享` 按钮。确认要替换的密钥后，点 `生成链接`，得到一个分享链接，形如 `https://hub.robonix.ai/d/<id>`。拿到链接的人无需登录即可查看部署清单和使用的软件包；在 Robonix Console 概览页的 `云端备份` 卡片中点 `导入分享链接`，粘贴链接后打开，可以点 `安装到这台机器人`。分享只包含部署清单，不包含原作者的本地软件包。点 `已分享` 可以复制链接或停止分享，停止后链接立即失效。分享页不出现在目录中。在线演示中不提供分享。

## 用量

`用量` 页显示账户在 Robonix Hub 中占用的存储空间：已用空间与上限、各类别的大小和条数、每份云端备份的版本数和大小，以及云端备份份数、每份备份保留的版本数和单份部署清单大小等上限。手机上从右上角的账户菜单进入。目前计入的只有云端备份。上传会超出上限时，上传被拒绝，已有的备份保持不变。

## API

Robonix Hub 提供只读 REST API，前缀为 `https://hub.robonix.ai/api/v1`。目录、软件包和能力约定无需令牌；账户、收藏和机器人需要个人访问令牌，在 [hub.robonix.ai](https://hub.robonix.ai) 侧栏的 `API` 页生成。接口说明见 `https://hub.robonix.ai/api/v1/openapi.json`。

## 服务状态

[hub.robonix.ai/status](https://hub.robonix.ai/status) 显示网站、数据库、账户与登录、邮件、目录同步和备份等是否正常，并链接到外部监控的历史可用率。
